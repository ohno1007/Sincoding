# 积木编辑器（前端）

> 路线图阶段 3。核心原则：**AST 是唯一真相源**——积木与文本都由 AST 派生，二者绝不直接互转。

```
文本编辑 ──reparse──► AST ──serializeSource──► 文本
积木拖拽 ──修改────► AST ──serializeBlocks──► 积木(JSON) ──► 渲染
```

## 单页 IDE：`index.html`

仿 Scratch 的积木编辑器，零依赖（纯 HTML/CSS/JS），线性描边图标。

- **仿 Scratch 的分类积木区**：左侧分类导航（彩色圆点 + 名称，点击/滚动联动高亮），右侧
  **「所见即所得」积木预览**——调色板里的积木与画布上长得**完全一致**（同一个渲染器），点一下即加入；
  过宽的积木在调色板里截断显示，**鼠标悬停即弹出完整积木**（浮在画布之上，不被宽度截断）。
- **运行高亮**：实时预览执行到哪个积木，画布上那个积木就**发光**（Scratch 风格 glow），直观看到执行流。
- **舞台控制台**：舞台页带控制台，`print` 输出实时打印到控制台；「打印积木信息」一键把当前精灵的
  函数/语句数/共享状态 dump 到控制台。
- **多精灵 / 多页积木**：底部精灵栏，每个精灵拥有自己的一页积木（program）与一组造型；切换精灵即切换积木页与造型集。
- **无限积木画布**：拖空白处平移、滚轮缩放，脚本可自由拖动摆放。
- **积木拖拽重排**：按住语句积木拖动，可在各 stack（函数体 / 控制块嘴巴）间移动；落点高亮提示，落下即改 AST 并刷新文本。
- **丰富积木集**：调色板分组覆盖搭游戏所需的常用积木，点击即加入选中脚本——
  - 变量/数据：设变量 / 字符串 / 数组 / 数组赋值 `a[i]=v`
  - 运算：变量 ±1 / `变量 ← 表达式` / `to_int` / `to_float`
  - 控制：`if` / `if…else` / `while` / `for i in a..b` / `return` / `print`
  - 舞台：初始化舞台 / **游戏主循环**（`while stage_running` 含 frame 开/合）/ frame / 关闭舞台
  - 运动（精灵）：新建精灵 / 移动到 x y / 前进 / 右转 / 面向 / 设大小 / 取精灵 x、y
  - 外观：载入造型 / 画出精灵 / 说 / 画文字 / 画数字
  - **画笔**：清空 / 设笔颜色 / 设笔粗细 / 画线 / 画点（持久绘制层，跨帧累积）
  - **平台 API**：鼠标 x/y、按下鼠标? / 随机数 / 屏幕宽高 / 帧数
  - 事件/声音：当按 ←→↑↓ / 广播 / 收到 / 播放音调 / 播放声音
  - 每个积木产出的文本都经规范引擎解析+编译验证（`tools/verify_palette_blocks.js`）。
- **积木 UI 全中文**：运行时函数在积木上以**中文**显示（初始化舞台 / 按下键? / 移动到 /
  画出精灵 / 画线 …），而右侧文本视图与导出仍是英文——「AST 唯一真相」，中文只是积木的一种视图。
- **舞台**：精灵以其当前造型为外观/纹理（画板里画什么，舞台上精灵就长什么样），可拖动摆位。
- **实时编辑预览**（`interp.js`）：内置积木解释器，直接在浏览器跑当前精灵程序，编辑即重跑（类 Vue）；
  支持键盘事件、广播、声音（Web Audio）。游戏主循环 `while stage_running()` 被逐帧（rAF）执行以不阻塞。
- **事件 / 声音积木**：调色板含 当按键/广播/收到/播放音调 等（对应运行时 `broadcast`/`received`/`play_tone`）。
- **多精灵并行**：预览把所有精灵的程序作为 actor 并行跑在同一舞台（共享世界、每帧只清一次屏）。
- **造型即外观（预览 = 成品）**：`sprite_load(name)` 在预览里画的就是造型本身——优先取同名
  painted 造型，否则按文件名加载造型 PNG（`assets/` 下），与导出成品 `sprite_load` 同源；
  画板造型、预览画面、成品纹理三者一致，改一处一起变。
- **项目级共享状态**：结构体 / 全局变量 / 数组属于整个项目，所有精灵共享同一组；任一精灵里
  增删全局，其它精灵立即可见，预览里各 actor 的环境栈底指向同一个共享作用域（一改全见）。
- **语法高亮**：文本框为透明 textarea 覆盖在高亮层之上，关键字/类型/字符串/数字/注释着色。
- **代码补全**：输入标识符前缀即弹出补全下拉，含关键字 / 类型 / 运行时函数（带中文名 + 形参
  签名提示）/ 本项目里的函数·变量·结构体名；↑↓ 选择、Enter/Tab 接受、Esc 关闭，Ctrl+Space 唤起。
- **语法/类型诊断**：复用 wasm 规范引擎的报错，编辑即检查；底部诊断面板按 `第N行` 列出
  类型不匹配 / 未声明变量 / 语法错误等，点一条即跳转到对应行。
- **保存 / 打开项目**：「保存项目」把整个项目（全部精灵的积木页 + 造型 + 项目级共享状态 +
  上次发布配置）存成 `.sinproj`；「打开项目」载入后即可继续编辑（造型以 PNG dataURL 内嵌）。
- **一键发布到多平台**：「发布」弹模态框填项目名 / 包名 / 图标(Logo) / 勾选平台，经本地构建
  服务 `tools/ide_server.py` 的 `/api/publish` 调既有 `build_*.sh`，把项目一键交叉编译到
  **Linux / Windows / Android / Web**，产物落在 `editor/dist/<名>/<平台>/` 并给出下载/打开链接。
  无构建服务（纯静态托管）时降级为下载 `.sin` 源码。导出的 `.sin` 仍会自动补全运行时
  `extern` 声明，可被 `build_native.sh` / `build_web.sh` 直接编译。
- **可编辑积木**：数字 / 变量 / 函数名直接点改，布尔积木点击切换；从调色板加入 `let / if / while / return / print` 积木。
- **实时文本写回**：任何积木编辑都即时更新右侧文本视图，结果与 `sinc --emit src` **逐字节一致**（由 `blockmodel.js` 保证，并有测试交叉验证）。
- **精灵造型画板**：画笔 / 橡皮 / 调色板 / 笔刷大小 / 清空 / 导出 PNG，支持多造型与缩略图。

```bash
tools/render_blocks.sh examples/fib.sin   # 生成 editor/blocks_data.js
# 纯静态：浏览器打开 editor/index.html（保存/打开项目、预览可用；发布降级为下载 .sin）
# 带构建：python3 tools/ide_server.py 8000 → http://127.0.0.1:8000/index.html（发布可一键编译多平台）
```

底层引擎：

- **AST → 文本**（`sinc --emit src`）：规范化序列化回源码，幂等且语义不变。
- **AST → 积木模型**（`sinc --emit blocks`）：导出积木 JSON，前端据此渲染。
- `blockmodel.js` 的 `modelToSource` 镜像 C++ `serializeSource`，保证积木编辑的写回与规范引擎对齐。
- **文本 → 积木（反向）**：把编译器编成 WebAssembly（`tools/build_sinc_wasm.sh` → `editor/sinc.{js,wasm}`），
  浏览器内直接调用规范引擎解析文本框内容，实时重建积木；语法/类型错时容错返回部分积木。
- `block_viewer.html`：只读积木查看器（轻量，供截图测试）。

`blocks_data.js` 为生成文件（默认内置 `fib` 示例）。
